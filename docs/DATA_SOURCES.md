# Data sources

Check each site's terms and robots.txt. Prefer official APIs. Cache raw downloads in `data/raw` so the demo never depends on a live site.

| Source | Use | Access |
|---|---|---|
| openFDA (drug and device label, device registration, UDI endpoints) | product and label text, metadata | REST API |
| DailyMed (SPL labels) | real medication label text and images | downloads and API |
| FDA GUDID | device identifiers, UDI-DI records | bulk download |
| 21 CFR Part 801 (device labeling), Part 201 (drug labeling), Part 830 (UDI) | requirement corpus | eCFR API |
| EU MDR 2017/745 Annex I chapter III and related guidance | requirement corpus | EUR-Lex |
| ISO 15223-1 symbol set | symbol list and reference artwork | check licensing, use public descriptions and redrawn or openly licensed icons |
| GS1 General Specifications | barcode and application identifier rules | GS1 public docs |
| Synthetic labels | CV training and error injection benchmark | generated by our own script |

Notes:
- Keep a `SOURCES.md` log with URL, fetch date and licence for every dataset.
- Do not scrape anything behind a login.
- Standard symbols may be copyrighted. Use openly available or redrawn versions and say so in the report.
